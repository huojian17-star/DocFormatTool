# 01-项目概览

## 是什么

**规范文档一键排版工具（DocFormatTool）**——学生上传任意格式文本（txt/md/docx）或学校模板，程序自动识别段落结构（标题/正文/摘要/关键词/参考文献）并套用模板格式排版成 docx。小红书/淘宝有类似付费服务，作者独立开发。

## 技术栈

- **UI**：tkinter（`app/main.py`），清爽浅色办公主题（学术蓝 #2563eb）
- **引擎**：`engine/`（infer.py 段落识别 + build_docx.py 排版生成）
- **模板**：`configs/presets/`（内置中文期刊单栏/双栏等模板 JSON，**必须打进 exe**）
- **授权**：`license/`（fingerprint 指纹 + keys 密钥 + version 版本/更新）
- **打包**：PyInstaller onefile，`DocFormatTool.spec`；onedir 备选 `DocFormatTool_onedir.spec`
- **ONNX 分类器**：`engine/role_classifier.onnx`（1.7MB，LightGBM 导出，见 [[07-ONNX训练]]）

## 核心处理流程

1. 输入：txt / md（`build()`）或 docx（`reformat_existing()`）
2. 段落识别：`infer._classify()` 按编号体系分类（数字/中文公文/混合/大写序号/无编号）
3. 层级修正：`_adjust_heading_level()`（同级递进、混合体系跟随）
4. 低置信确认：弹窗让用户确认拿不准的段落（见 [[03-更新链路]] 同期的弹窗功能）
5. 排版生成：套模板样式（标题 1/2/3、摘要/关键词/参考文献自定义样式、题目 Title）
6. 质检：自动 QC + 可选改动报告

## 标题识别体系（2026-08 实测通过）

| 体系 | 一级 | 二级 | 三级 |
|---|---|---|---|
| 数字 | 第一章 / 1 | 1.1 | 1.1.1 |
| 中文公文 | 一、 | （一） | 1. |
| 混合 | 一、 | 1.1 | （1） |
| 纯数字 | 1 | 1.1 | 1.1.1 |
| 大写序号 | 壹、 | （壹） | ① |

无编号大字号标题也识别；脚注/数据来源（含 URL、注：、数据来源于）不误判为标题。

## 目录结构要点

- `app/main.py` — 主程序（GUI + 更新 + 弹窗确认）
- `engine/` — 识别与排版引擎
- `license/version.py` — 版本常量、check_update、download、selftest、build_updater_bat
- `configs/presets/` — 内置模板 JSON
- `site/` — 测试脚本、训练脚本、发布脚本
- `wiki/` — 本知识库
