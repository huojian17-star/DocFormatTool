# 03-更新链路

## 机制设计

1. 启动后台线程 `check_update()`：请求 version.json 三通道（ghfast → raw → jsdelivr）
2. 有新版 → 弹窗"发现新版本"（显示 note + 蓝奏云链接 + "自动更新"按钮）
3. 点"自动更新" → 主线程建进度窗口 → 子线程 `download()` 下载到 `DocFormatTool_new.exe`
4. 写 `update.bat` → `os.startfile(bat)` → 主程序退出
5. bat：等 2s → taskkill 主程序 → 等 2s → copy 覆盖 → 校验（errorlevel + 大小>10MB）→ 清 _MEI → 等 3s → **explorer 启动新版** → 自删

## ⚠️ 五连 bug 战役（v1.0.9 → v1.0.14，全部踩过）

| # | bug | 现象 | 根因 | 修复 |
|---|---|---|---|---|
| 1 | 按钮无反应 | 点"自动更新"弹窗不关、毫无反应 | 回调 `lambda: (win.destroy(), ...)` 里 `win` 未定义 → NameError 被 Tkinter 静默吞 | 回调签名接收 win：`lambda w: (w.destroy(), ...)` |
| 2 | 进度窗口不显示 | 点了没反应（同 1 表象） | 进度窗口在子线程创建（tkinter 控件不能子线程创建） | 主线程先建窗口，子线程只更新 |
| 3 | 失败无提示 | 失败弹窗 lambda 闭包失效 | `lambda e=e:` 忘写默认参数，延迟执行时 e 已释放 | 加默认参数捕获 |
| 4 | APP_NAME 未定义 | 下载成功但弹"更新失败" | updater bat 模板里 `APP_NAME` 在 app/main.py 未定义（只在 license/version.py） | `version_mod.APP_NAME` + 把 bat 生成移入 `version.build_updater_bat()` 并纳入 selftest |
| 5 | 更新后无法重启 | 下载替换成功但重启弹 LoadLibrary | **bat 的 `start "" "exe"` 从 cmd 会话启动 GUI 程序，DLL 加载环境异常** | **改 `explorer "exe"`（= 双击路径，Explorer GUI 会话）→ 根治** |

## 关键教训

- **自动重启必须用 `explorer` 而不是 `start`**（GUI 程序从 cmd 会话启动有 DLL 加载差异，实测必现 LoadLibrary）
- **selftest 要覆盖 GUI 走的全部路径**（检查→下载→sha256→bat 生成），曾漏 bat 生成环节导致 APP_NAME bug 漏网
- 更新相关代码每次都要跑 `site/test_replace_chain.py`（隔离目录完整链路：主进程运行中 → bat 替换 → 新版启动）

## `--selftest` 自测模式

```bash
DocFormatTool.exe --selftest [--keep]
```
自动执行：检查 version.json → 发现新版 → 下载 full_url → sha256 校验 → build_updater_bat 生成验证 → 输出 [OK]/[FAIL]。**发版前必跑**，链路不通不发布。

## 更新链路相关文件

- `license/version.py`：check_update / download(sha256) / build_updater_bat / selftest / get_exe_path
- `app/main.py`：`_start_download` / `_download_and_update` / `_show_links_window`
- `site/test_replace_chain.py`：隔离完整链路测试
- `site/test_update_chain.py`：GUI 按钮 + 下载链路测试
