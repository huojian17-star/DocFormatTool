# 04-测试方法

## 发版质检双保险

1. **OpenXML 断言**：`python -X utf8 site/test_heading_suite.py` — 六场景标题层级，6/6 绿
2. **PDF 渲染 + 视觉检查**：`site/render_suite_pdf.py` 转 PDF → MiniMax 视觉 `_call_minimax` 检查
   - ⚠️ **必须高清单页（dpi≥150、单页不拼图）**——拼图缩放会误导视觉误判字号层级（T3 曾误报）

## 六场景标题回归（test_heading_suite.py）

| 场景 | 编号风格 | 覆盖点 |
|---|---|---|
| 1 | 第一章 / 1.1 / 1.1.1 | 数字体系 |
| 2 | 一、/（一）/ 1. | 中文公文体系 |
| 3 | 混合 一、/ 1.1 /（1） | 混合体系（（1）不误判 H1） |
| 3+ | 多组 一、→（一）→ 1. 循环 | 同级延续 |
| 4 | 无编号短行标题 | H1→H2 递进 |
| 5 | 纯数字 1 / 1.1 / 1.1.1 | 纯数字 |
| 6 | 壹、/（壹）/ ① | 大写序号 |

## 真实文档回归

- 测试包：`F:\论文排版工具_测试包\`（学生输入_思政论文.docx、毕业论文_人工智能...、管理2304...）
- 完整流程：真实 docx → reformat → 检查 pStyle → 质检
- 法条/公文文档（gov 语料 txt）：`_mark_cover` 封面区限 12 条 + 第 X 条边界，build 兜底全 cover 转正文（内容不丢）

## 更新链路测试（见 [[03-更新链路]]）

- `site/test_replace_chain.py`：隔离目录完整替换（主进程运行中 → bat → 新版启动）
- `DocFormatTool.exe --selftest`：发版前自动验证
- `site/test_path_hypo.py`：干净 PATH vs 完整 PATH 启动对比（排查 conda DLL 假说用）

## 样式区测试

- `site/test_style_zone.py`：摘要/关键词/参考文献/题目/脚注的样式断言（自定义样式进样式集）

## 视觉工具链（reasonix 全局）

- `tools/ocr.py`：精确文字（RapidOCR），文字类一律走它（VLM 会脑补）
- `tools/vision.py`：视觉语义（qwen3.5:latest = 9B）
- MiniMax 视觉 `mcp__minimax-vision__see_image` / `_call_minimax`：2-3s 快速检查
